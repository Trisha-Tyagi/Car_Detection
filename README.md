# 🚗 Simple Car Detection from Webcam using OpenCV

This project performs basic car detection using a webcam feed with OpenCV's pre-trained Haar Cascade classifier. It's designed to demonstrate real-time object detection in a lightweight, beginner-friendly setup.

---

## 📌 Features

- Detects cars from your webcam in real-time
- Uses Haar Cascade Classifier (`haarcascade_car.xml`)
- Lightweight and easy to run
- Great for learning OpenCV basics

---

## 🛠️ Technologies Used

- Python
- OpenCV
